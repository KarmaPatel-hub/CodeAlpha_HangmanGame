#  Hangman Game

A simple text-based Hangman Game built using Python as part of my Python Programming Internship at CodeAlpha.

##  Project Overview
In this game, the player tries to guess a hidden word one letter at a time.  
The player has only 6 incorrect attempts to guess the word correctly.


##  Features
- Random word selection
- Limited incorrect guesses
- Interactive console gameplay
- Displays guessed letters
- Beginner-friendly Python project


##  Technologies Used
- Python
- Random Module


##  Concepts Learned
- Loops (`while`)
- Conditional Statements (`if-else`)
- Lists and Strings
- Functions
- User Input Handling
- Basic Game Logic
